Faces use your browser's built-in Shape Detection API (real on-device AI — best supported on Chrome/Edge). Motion and Objects use classical computer-vision heuristics (frame differencing and edge/contour detection) — they draw boxes around moving or high-contrast regions but don't name what's in them (no "car" or "dog" labels). Detections render as an AR HUD (bracket reticles, pulsing lock-on dot, floating tag with a rough % of frame). Pick a face filter to swap the face reticle for a tracked AR overlay (glasses, hat, bunny ears, crown), and use Snapshot to save the current view with all overlays baked in. For full multi-class object recognition, use the Python version instead.
